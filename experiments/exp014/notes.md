# exp014 — exp010(疑問形, 最良) + exp009("[Ops] "最小タグ) の合成テスト

exp010（疑問形, N=300フルで score=8.73・fire rate 97.0%、現状最良）と exp009
（"[Ops] " 最小タグ, N=30smokeで90%・誤差範囲内）を合成し、相加的な効果が出るか
（あるいは干渉して悪化するか）を検証する。

## 狙い

exp009単体（exp006ベース）では有意な改善は見えなかったが、より高い/安定した
ベースライン（exp010）の上に載せた場合にどうなるかは別問題。トーン変更同士の
合成なので、構造変更（exp011で悪化確認済み）とは異なりリスクは低いと予想。

## 実装（`attack.py`）

- exp010 の12疑問形テンプレートに `_AUTHORITY_TAG = "[Ops] "` を前置。
- 宛先生成・N=300・EXFIL_FRACTION=0 は exp010 と完全に同一。

## 評価結果（make eval EXP=exp014 MODELS=gemma_4 CANDIDATES=30, smoke）

findings 25/30 → **fire rate 83.3%**（exp010単体のsmoke実測96.7%より明確に悪化）。

## 結論

「[Ops] タグは exp009 単体では誤差範囲内、より高いベースライン(exp010)に載せれば
相加的に効くかもしれない」という仮説は**否定**された。疑問形（トーン変更）と
権威タグ（構造への軽微な追加）は相加的に合成されず、むしろ干渉して悪化する。
トーン変更同士でも安易に重ねてよいわけではないという教訓。**不採用**、exp010
単体（タグなし・疑問形のみ）を最良のプレーンDEPUTY文面として維持する。
